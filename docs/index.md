# libiio-conv

Fast conversion between IIO buffer samples and host arrays (type change, I/Q
pairing, layout, scaling) for libiio v1, with SIMD kernels chosen at run time,
and MATLAB bindings for libiio v1 built on it.

The C library is described in the
[README](https://github.com/tfcollins/libiio-conv#readme) of the repository.
